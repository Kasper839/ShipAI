# Security Policy

## Supported Versions

Please use the latest released version of ShipAI to ensure you have all security patches.

| Version | Supported |
| ------- | --------- |
| v1.4.x  | ✅        |
| < v1.4  | ❌        |

## Reporting a Vulnerability

If you discover a security vulnerability within ShipAI, please report it privately. 
**Do not create a public GitHub issue for security vulnerabilities.**

You can report it by:
- Opening a security advisory on the GitHub repository under the **Security** tab.
- Or by sending an email to [vojtechkaspar7@gmail.com].

We will review your report and work on a fix as soon as possible. Thank you for keeping ShipAI secure!
